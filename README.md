# GellyClick Mother's Day Sample

A responsive, single-page Mother's Day greeting website. It includes an interactive letter popup, heartfelt message, reasons-to-love-you cards, and a hug button. No backend, API key, countdown, or background music is required.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `gellyclick-mothers-day`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, the expected URL is `https://YOUR-USERNAME.github.io/gellyclick-mothers-day/`.

## Customize it
- Edit the letter and sign-off in `index.html` to personalize it for the recipient.
- Replace the sample Unsplash image URL with a photo you have permission to use.
- The sample copy is generic; change “Mom” or “your forever baby” to suit the sender and recipient.
